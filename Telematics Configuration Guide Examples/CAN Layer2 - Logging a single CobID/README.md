# CAN Layer2 - Logging a Single CobID

Companion project for the step-by-step guide in the [Telematics Configuration Guide](https://docs.proemion.com/docs/telematics_configuration_guide_en/index.html).

It shows how to receive a single CAN message (CAN L2, one CobID) on a CANlink® mobile 10000 and log its raw payload to the Data Platform, using the [CANlink_CAN](https://github.com/Proemion/codesys-examples/tree/main/CAN%20Layer2%20-%20Signal%20Based%20Logging) abstraction library.

Follow the guide for the full walkthrough — this folder is the ready-to-open `.projectarchive` for those who want the finished result instead of building it step by step.
